# Ore to Empire v1.2.0

**[1.2.0] - 2026-10-07**

### เพิ่มใหม่
- **แผนที่ใหญ่ขึ้น 4 เท่า (64×64 ช่อง, ที่ดิน 64 แปลง)** โรงงานเดิมอยู่ตรงกลางเป็น "โซนบ้าน" รอบนอกมี 5 โซนใหม่ ทิศตายตัว รูปร่างสุ่มตาม seed
  - ป่า (ตะวันตก): ต้นไม้ ทุ่งดอกไม้
  - แม่น้ำ (ใต้โซนบ้าน): ปลาน้ำจืด ดินเหนียวริมตลิ่ง
  - ทะเล (ขอบล่าง): ปลาทะเล สาหร่าย
  - ทะเลทราย (ตะวันออก): น้ำมันดิบ แร่ทองคำ ทราย
  - ภูเขาไฟ (เหนือ): กำมะถัน ออบซิเดียน ปล่องความร้อน
- **ใบอนุญาตโซน** ซื้อในเมนู "ขยายกิจการ" (แทนเมนูขายกิจการ) หรือแตะที่ดินของโซนนั้น ต้องวิจัยให้เสร็จก่อน ใบอนุญาตแต่ละใบให้หุ้นนักลงทุน
  - ป่า $30K (+2 หุ้น) · แม่น้ำ $40K (+2) · ทะเล $150K (+3) · ทะเลทราย $250K (+4) · ภูเขาไฟ $800K (+6)
  - ที่ดินในโซนใหม่: ราคาตั้งต้นของโซน × 1.35 ต่อแปลงที่มีในโซนนั้น · โซนบ้านใช้ราคาเดิม
- **อาคารใหม่ 8 แบบ:** ท่าประมง ฟาร์มสาหร่าย บ่อดินเหนียว โรงตัดไม้ สวนดอกไม้ บ่อน้ำมัน โรงกลั่น โรงไฟฟ้าความร้อนใต้พิภพ (60 MW ต้องวางทับปล่องภูเขาไฟ)
- **สินค้าใหม่ 22 ชนิด** ไปจนถึงระดับ 7: อิฐ ถ่านไม้ ทองคำแท่ง พลาสติก เลนส์ เชื้อเพลิงจรวด อาหารกระป๋อง น้ำหอม เครื่องประดับ ชิปขั้นสูง ดาวเทียม จรวด
  - ตลาดมีหมวดใหม่: อาหาร ของหรู อวกาศ แต่ละเมืองให้ราคาต่างกัน
- **งานวิจัยใหม่ 7 หัวข้อ** รวมคอลัมน์ใหม่ "อวกาศ": ป่าไม้ ประมง ประมงทะเล ปิโตรเลียม ธรณีวิทยา ไมโครชิป อวกาศ
- **สายพานข้ามน้ำได้** เป็นสะพาน ราคาช่องละ $10 (บนดิน $2) ระบบหาเส้นทางจะอ้อมน้ำถ้าไม่ไกล
- โรงไฟฟ้าถ่านหินใช้ถ่านไม้เป็นเชื้อเพลิงได้
- แตะต้นไม้ ทุ่งดอกไม้ น้ำ หรือปล่องภูเขาไฟ จะมีปุ่มสร้างอาคารที่ใช้กับช่องนั้นได้
- ภารกิจใหม่ 6 ข้อ: เปิดโซนป่า แม่น้ำ ทะเล ทะเลทราย ภูเขาไฟ และปล่อยจรวดลำแรก

### เปลี่ยนแปลง
- **เอาการขายกิจการ (รีเซ็ตโรงงาน) ออก** หุ้นที่มีอยู่ยังใช้ได้ และยังเพิ่มราคาขาย 2% ต่อหุ้นเหมือนเดิม
- สิทธิพิเศษที่ใช้ได้เฉพาะหลังขายกิจการ (เงินตั้งต้น, คลังสิทธิบัตร, ธนาคารที่ดิน) ถูกลบ และคืนหุ้นให้ครบทุกเลเวล
- สิทธิพิเศษใหม่: นายหน้าที่ดิน (ที่ดิน −8%/เลเวล) · ห้องแล็บวิจัย (วิจัยเร็วขึ้น 10%/เลเวล) · เหล็กราคาส่ง (สายพานและสะพาน −10%/เลเวล)
- ภารกิจ "ทำเงิน $1M แล้วขายกิจการ" เปลี่ยนเป็นภารกิจเปิดโซน
- หน้าต่าง "มีอะไรใหม่" แจ้งผู้เล่นเดิมเรื่องโซนใหม่

### เซฟ
- **รูปแบบเซฟเวอร์ชัน 4** เซฟเดิมย้ายให้อัตโนมัติ: แผนที่เดิมย้ายไปอยู่ตรงกลาง อาคาร สายพาน และสายแร่หายากเลื่อนตามไป +16 ช่อง ที่ดินที่ซื้อไว้ยังเป็นของผู้เล่น ไม่มีอะไรหายไป
- เพิ่มช่อง `world.terrain` และ `licences`
- เวอร์ชันเก่าเปิดเซฟเวอร์ชัน 4 ไม่ได้

## ไฟล์ในโฟลเดอร์นี้

- `index.html` — เปิดด้วยเบราว์เซอร์เพื่อเล่นเวอร์ชันนี้ได้ทันที (เซฟแยกจากเวอร์ชันอื่น)
- `update-from-v1.1.1.patch` — โค้ดที่เปลี่ยนจาก v1.1.1

## อัปเดตโค้ดจาก v1.1.1 เป็น v1.2.0

ถ้าโฟลเดอร์โปรเจกต์มีประวัติ git (มาจาก zip ชุดนี้):

```bash
git checkout v1.2.0
npm install
```

ถ้าโฟลเดอร์เป็นโค้ด v1.1.1 แบบไม่มี git:

```bash
git apply releases/v1.2.0/update-from-v1.1.1.patch
npm install
```
