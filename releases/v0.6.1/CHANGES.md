# Ore to Empire v0.6.1

**[0.6.1] - 2026-10-06**

### แก้ไข
- **สูตรการผลิตไม่ชัด** (โรงประกอบขั้นสูง เช่น มอเตอร์): แสดงชื่อวัตถุดิบครบทุกตัว ไม่ใช่แค่ไอคอน
- ช่อง "วัตถุดิบ" แสดง มี/ต้องใช้ ของแต่ละอย่าง ตัวที่ขาดเป็นสีแดง
- รายการสูตรแสดงเฉพาะสูตรที่ใช้อยู่ กด "เปลี่ยนสูตร" เพื่อดูทั้งหมด
- ไอคอนที่เคยคล้ายกันเปลี่ยนรูปร่างให้แยกออก: เหล็กแท่ง, เหล็กกล้า, กระจก, สายไฟ, มอเตอร์ (ทั้งในหน้าต่างและบนสายพาน)

### เซฟ
- ใช้เซฟเดิมได้

## ไฟล์ในโฟลเดอร์นี้

- `index.html` — เปิดด้วยเบราว์เซอร์เพื่อเล่นเวอร์ชันนี้ได้ทันที (เซฟแยกจากเวอร์ชันอื่น)
- `update-from-v0.6.0.patch` — โค้ดที่เปลี่ยนจาก v0.6.0

## อัปเดตโค้ดจาก v0.6.0 เป็น v0.6.1

ถ้าโฟลเดอร์โปรเจกต์มีประวัติ git (มาจาก zip ชุดนี้):

```bash
git checkout v0.6.1
npm install
```

ถ้าโฟลเดอร์เป็นโค้ด v0.6.0 แบบไม่มี git:

```bash
git apply releases/v0.6.1/update-from-v0.6.0.patch
npm install
```
