# Ore to Empire v0.7.0

**[0.7.0] - 2026-10-06**

### เพิ่มใหม่
- **ปุ่ม "จัดสายพาน"** (มุมขวาล่างของแผนที่): คำนวณเส้นทางสายพานใหม่ทั้งหมดพร้อมกัน ให้ข้ามกันน้อยลงและวิ่งขนานเป็นแนว อาคารอยู่ที่เดิม
  - แสดงตัวอย่างเส้นทางใหม่เป็นสีเขียว พร้อมตัวเลขเทียบจุดข้ามและความยาว ก่อนกด "ใช้ผังนี้"
  - ฟรี ถ้าความยาวรวมไม่เพิ่ม ถ้าเพิ่มคิด $2 ต่อช่อง
  - จัดเฉพาะสายพานของอาคารเดียวได้จากหน้าต่างอาคาร
- **ปุ่มมุมมองสายพาน:** ทั้งหมด / จาง / เฉพาะของอาคารที่เลือก
- สีขอบสายพานตามสินค้าที่ขน, จุดข้ามวาดเป็นสะพานลอย, สายพานบางลงเมื่อซูมออก

## ไฟล์ในโฟลเดอร์นี้

- `index.html` — เปิดด้วยเบราว์เซอร์เพื่อเล่นเวอร์ชันนี้ได้ทันที (เซฟแยกจากเวอร์ชันอื่น)
- `update-from-v0.6.1.patch` — โค้ดที่เปลี่ยนจาก v0.6.1

## อัปเดตโค้ดจาก v0.6.1 เป็น v0.7.0

ถ้าโฟลเดอร์โปรเจกต์มีประวัติ git (มาจาก zip ชุดนี้):

```bash
git checkout v0.7.0
npm install
```

ถ้าโฟลเดอร์เป็นโค้ด v0.6.1 แบบไม่มี git:

```bash
git apply releases/v0.7.0/update-from-v0.6.1.patch
npm install
```
