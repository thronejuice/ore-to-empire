## ไฟล์ในโฟลเดอร์นี้

- `index.html` — เปิดด้วยเบราว์เซอร์เพื่อเล่นเวอร์ชันนี้ได้ทันที (เซฟแยกจากเวอร์ชันอื่น)
- `update-from-v0.3.0.patch` — โค้ดที่เปลี่ยนจาก v0.3.0

## อัปเดตโค้ดจาก v0.3.0 เป็น v0.4.0

ถ้าโฟลเดอร์โปรเจกต์มีประวัติ git (มาจาก zip ชุดนี้):

```bash
git checkout v0.4.0
npm install
```

ถ้าโฟลเดอร์เป็นโค้ด v0.3.0 แบบไม่มี git:

```bash
git apply releases/v0.4.0/update-from-v0.3.0.patch
npm install
```
