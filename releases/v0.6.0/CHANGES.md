# Ore to Empire v0.6.0

**[0.6.0] - 2026-10-06**

### เปลี่ยนแปลง
- **การย้ายอาคารมีค่าใช้จ่าย** 10% ของมูลค่าอาคาร (ราคาสร้าง + ค่าอัปเกรด) ขั้นต่ำ $10
  - ย้ายฟรีภายใน 1 นาทีหลังสร้าง
  - สำนักงานใหญ่ค่าย้ายคงที่ $1,000
  - ราคาแสดงบนปุ่ม "ย้าย" และในแถบคำแนะนำ

### เพิ่มใหม่
- งานวิจัย **"โลจิสติกส์ภายในโรงงาน"** ($12,000) ลดค่าย้ายครึ่งหนึ่ง

### เซฟ
- ใช้เซฟเดิมได้ อาคารจากเซฟเก่าคิดค่าย้ายตามปกติ (ไม่มีช่วงย้ายฟรี)

## ไฟล์ในโฟลเดอร์นี้

- `index.html` — เปิดด้วยเบราว์เซอร์เพื่อเล่นเวอร์ชันนี้ได้ทันที (เซฟแยกจากเวอร์ชันอื่น)
- `update-from-v0.5.0.patch` — โค้ดที่เปลี่ยนจาก v0.5.0

## อัปเดตโค้ดจาก v0.5.0 เป็น v0.6.0

ถ้าโฟลเดอร์โปรเจกต์มีประวัติ git (มาจาก zip ชุดนี้):

```bash
git checkout v0.6.0
npm install
```

ถ้าโฟลเดอร์เป็นโค้ด v0.5.0 แบบไม่มี git:

```bash
git apply releases/v0.6.0/update-from-v0.5.0.patch
npm install
```
