# Ore to Empire v0.2.0

**[0.2.0] - 2026-10-05 · เฟส 2–3**

### เพิ่มใหม่ (เฟส 2)
- สินค้า 5 ระดับ 21 ชนิด จนถึงรถยนต์ไฟฟ้า และโรงประกอบขั้นสูง
- งานวิจัย 23 เรื่อง 5 หมวด (เดินต่อตอนออฟไลน์)
- ซื้อที่ดินเพิ่มได้ ทรายและยูเรเนียมอยู่บนที่ดินรอบนอก
- ตลาด 5 เมือง ราคาขึ้นลงตามอุปสงค์ และข่าวตลาด
- รถบรรทุก รถไฟ เรือ และท่าขนส่งสินค้า
- แผงโซลาร์ แบตเตอรี่ โรงไฟฟ้านิวเคลียร์

### เพิ่มใหม่ (เฟส 3)
- ขายกิจการแลกหุ้น พร้อมสิทธิพิเศษถาวร 6 อย่าง
- สัญญาจ้าง และภารกิจรายวัน (ได้เพชรสูงสุด 25/วัน)
- เสียงเอฟเฟกต์ และเมนูสำหรับมือถือ

### เซฟ
- เซฟเฟส 1 ย้ายมาใช้ต่อได้อัตโนมัติ (เซฟเวอร์ชัน 2)

---

## ไฟล์ในโฟลเดอร์นี้

- `index.html` — เปิดด้วยเบราว์เซอร์เพื่อเล่นเวอร์ชันนี้ได้ทันที (เซฟแยกจากเวอร์ชันอื่น)
- `update-from-v0.1.0.patch` — โค้ดที่เปลี่ยนจาก v0.1.0

## อัปเดตโค้ดจาก v0.1.0 เป็น v0.2.0

ถ้าโฟลเดอร์โปรเจกต์มีประวัติ git (มาจาก zip ชุดนี้):

```bash
git checkout v0.2.0
npm install
```

ถ้าโฟลเดอร์เป็นโค้ด v0.1.0 แบบไม่มี git:

```bash
git apply releases/v0.2.0/update-from-v0.1.0.patch
npm install
```
