# Ore to Empire v1.1.1

**[1.1.1] - 2026-10-06**

### ปรับปรุง
- **หน้าแนะนำวิธีเล่นมีรูปตัวอย่างที่ขยับได้** (หน้า 2 และ 3) วาดด้วยสีและไอคอนเดียวกับในเกม มีจุดแตะจำลองกดปุ่มจริงให้ดูทีละขั้น
  - หน้า 2: กด "สร้าง" → เลือกเครื่องขุดแร่ → แตะสายแร่เหล็ก → แตะเครื่องขุด → "ต่อสายพาน" → แตะสำนักงานใหญ่ → แร่วิ่งไปขาย มีเงินเด้งให้เห็น
  - หน้า 3: ต่อสายพาน เครื่องขุด → เตาหลอม และ เตาหลอม → สำนักงานใหญ่ แร่ 2 ก้อนเข้าเตา ออกมาเป็นเหล็กแท่ง 1 แท่ง
  - ข้อความบอกขั้นตอน ①–④ เปลี่ยนตามจังหวะนิ้ว · วนซ้ำเรื่อยๆ และเริ่มใหม่ทุกครั้งที่เปิดหน้า
  - ถ้าตั้งค่าเครื่องให้ลดการเคลื่อนไหว จะแสดงภาพนิ่งตอนต่อเสร็จ พร้อมรายการขั้นตอนครบ
- หน้าต่าง "มีอะไรใหม่" แจ้งผู้เล่นเดิมเรื่องรูปตัวอย่างใหม่

## ไฟล์ในโฟลเดอร์นี้

- `index.html` — เปิดด้วยเบราว์เซอร์เพื่อเล่นเวอร์ชันนี้ได้ทันที (เซฟแยกจากเวอร์ชันอื่น)
- `update-from-v1.1.0.patch` — โค้ดที่เปลี่ยนจาก v1.1.0

## อัปเดตโค้ดจาก v1.1.0 เป็น v1.1.1

ถ้าโฟลเดอร์โปรเจกต์มีประวัติ git (มาจาก zip ชุดนี้):

```bash
git checkout v1.1.1
npm install
```

ถ้าโฟลเดอร์เป็นโค้ด v1.1.0 แบบไม่มี git:

```bash
git apply releases/v1.1.1/update-from-v1.1.0.patch
npm install
```
