# Ore to Empire v1.3.1

**[1.3.1] - 2026-10-07**

### ปรับปรุง
- **ตั้งค่าเก็บสำรองในโกดังได้ทันที ไม่ต้องรอของเข้ามาก่อน:** รายการสินค้าดึงจากสายพานขาเข้า ของที่ยังไม่มีแสดงเป็น "ยังไม่มีของ · มาจาก…" พร้อมชื่ออาคารต้นทาง
  - สายพานที่มาจากโกดังอีกหลัง: ใช้ชนิดที่ตั้งคัดแยกไว้ หรือถ้าเป็นอัตโนมัติ จะไล่ย้อนดูของที่โกดังต้นทางมีและที่ไหลเข้าโกดังนั้น (ไล่ต่อได้หลายทอด กันวนซ้ำ)
  - ของที่ตั้งเก็บสำรองไว้ยังแสดงในรายการแม้ของหมดแล้ว
- **เลือกจำนวนเก็บสำรองได้ในครั้งเดียว:** กดปุ่ม "เก็บ …" แล้วเลือกจากแถบตัวเลือก (ไม่เก็บ, 10, 25, 50, 100, 200, 500, 1000, ทั้งหมด) แทนการกด −/+ ทีละขั้น
- ตัวเลือก "สายพานนี้ส่งอะไร" ใช้รายการเดียวกัน จึงตั้งคัดแยกได้ก่อนของมาถึงเช่นกัน

### เซฟ
- ใช้เซฟเดิมได้ ไม่มีการเปลี่ยนรูปแบบเซฟ

## ไฟล์ในโฟลเดอร์นี้

- `index.html` — เปิดด้วยเบราว์เซอร์เพื่อเล่นเวอร์ชันนี้ได้ทันที (เซฟแยกจากเวอร์ชันอื่น)
- `update-from-v1.3.0.patch` — โค้ดที่เปลี่ยนจาก v1.3.0

## อัปเดตโค้ดจาก v1.3.0 เป็น v1.3.1

ถ้าโฟลเดอร์โปรเจกต์มีประวัติ git (มาจาก zip ชุดนี้):

```bash
git checkout v1.3.1
npm install
```

ถ้าโฟลเดอร์เป็นโค้ด v1.3.0 แบบไม่มี git:

```bash
git apply releases/v1.3.1/update-from-v1.3.0.patch
npm install
```
