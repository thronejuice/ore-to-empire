# Ore to Empire v1.3.0

**[1.3.0] - 2026-10-07**

### เพิ่มใหม่
- **การ์ดแจ้งเตือนที่ค้างจนกดปิด** ด้านบนกลางจอ ไม่บังแผนที่
  - วิจัยเสร็จ: บอกชื่อหัวข้อและสิ่งที่ปลดล็อก (อาคาร สินค้า ใบอนุญาตโซน เมือง ยานพาหนะ หรือผลที่ได้) พร้อมปุ่ม "วิจัยต่อ" และจำนวนหัวข้อที่พร้อมวิจัย
  - สัญญาสำเร็จ: บอกสินค้าและเงินรางวัล พร้อมปุ่ม "ดูสัญญาใหม่"
  - งานวิจัยที่เสร็จระหว่างปิดเกม ก็ขึ้นการ์ดตอนกลับมาด้วย
- **ป้าย "✓ วิจัยต่อ" บนแถบด้านบน** กระพริบเมื่อห้องวิจัยว่างและมีหัวข้อที่วิจัยได้
- **แจ้งเตือนตอนเปิดแท็บอื่น:** ชื่อแท็บเปลี่ยนเป็น "✓ วิจัยเสร็จ" หรือ "⚠ สัญญาใกล้หมดเวลา" และมีแจ้งเตือนของเบราว์เซอร์ (ถ้าอนุญาต) เมื่อวิจัยเสร็จ หรือเมื่อสัญญาที่ยังส่งไม่ครบเหลือเวลา 5 นาที
  - ถามครั้งเดียวหลังเริ่มวิจัยครั้งแรก · เปิด/ปิดได้ในหน้าตั้งค่า
  - สัญญาสำเร็จระหว่างอยู่แท็บอื่นแจ้งไม่ได้ เพราะเกมหยุดคำนวณ จะขึ้นเป็นการ์ดเมื่อกลับมา
- **โกดังคัดแยกได้:** สายพานขาออกแต่ละเส้นเลือกได้ว่าส่งสินค้าชนิดไหน หรือ "อัตโนมัติ (ทุกอย่าง)" แบบเดิม
- **โกดังเก็บสำรองได้:** ตั้งจำนวนที่เก็บไว้แยกทีละชนิดด้วยปุ่ม −/+ (10, 25, 50, 100, 200, 500, 1000, ทั้งหมด) ส่งออกเฉพาะส่วนที่เกิน

### เปลี่ยนแปลง
- ข้อความเล็กมุมจอตอนวิจัยเสร็จและสัญญาสำเร็จ เปลี่ยนเป็นการ์ดแทน

### เซฟ
- ใช้เซฟเดิมได้ เพิ่มช่องแบบไม่บังคับ: `belts[].filter`, `buildings[].reserve`, `settings.notify` ไม่เปลี่ยนเลขรูปแบบเซฟ

## ไฟล์ในโฟลเดอร์นี้

- `index.html` — เปิดด้วยเบราว์เซอร์เพื่อเล่นเวอร์ชันนี้ได้ทันที (เซฟแยกจากเวอร์ชันอื่น)
- `update-from-v1.2.1.patch` — โค้ดที่เปลี่ยนจาก v1.2.1

## อัปเดตโค้ดจาก v1.2.1 เป็น v1.3.0

ถ้าโฟลเดอร์โปรเจกต์มีประวัติ git (มาจาก zip ชุดนี้):

```bash
git checkout v1.3.0
npm install
```

ถ้าโฟลเดอร์เป็นโค้ด v1.2.1 แบบไม่มี git:

```bash
git apply releases/v1.3.0/update-from-v1.2.1.patch
npm install
```
