# Ore to Empire v0.5.0

**[0.5.0] - 2026-10-06**

### เพิ่มใหม่
- **เกรดแร่:** ทุกช่องแร่มีเกรด ต่ำ ×0.6 / ปกติ ×1 / สูง ×1.5 ดูได้จากความถี่ของประกายแร่
- แตะช่องแร่ว่างเพื่อดูชนิด เกรด และปุ่ม "สร้างเครื่องขุดที่นี่"
- **สายแร่ร่ำรวย:** โผล่เป็นระยะ ขุดเร็ว ×3 มีปริมาณจำกัด หลอดคงเหลือ และแจ้งเตือนเมื่อเหลือ 25%
  - ไม่มีคนขุดภายใน 20 นาทีจะหายไป
  - หยุดนับตอนออฟไลน์ ไม่หมดหรือหายระหว่างผู้เล่นไม่อยู่
  - ปุ่ม ✦ ด้านบนพาไปที่สายแร่

### เซฟ
- ใช้เซฟเดิมได้ แผนที่เดิมได้เกรดแร่เพิ่มอัตโนมัติ (เซฟเวอร์ชัน 3)

---

## ไฟล์ในโฟลเดอร์นี้

- `index.html` — เปิดด้วยเบราว์เซอร์เพื่อเล่นเวอร์ชันนี้ได้ทันที (เซฟแยกจากเวอร์ชันอื่น)
- `update-from-v0.4.0.patch` — โค้ดที่เปลี่ยนจาก v0.4.0

## อัปเดตโค้ดจาก v0.4.0 เป็น v0.5.0

ถ้าโฟลเดอร์โปรเจกต์มีประวัติ git (มาจาก zip ชุดนี้):

```bash
git checkout v0.5.0
npm install
```

ถ้าโฟลเดอร์เป็นโค้ด v0.4.0 แบบไม่มี git:

```bash
git apply releases/v0.5.0/update-from-v0.4.0.patch
npm install
```
