# Ore to Empire v1.2.1

**[1.2.1] - 2026-10-07**

### ปรับปรุง
- **หน้าวิจัยแบ่งเป็น 3 แท็บ:** ทำได้ตอนนี้ (เปิดมาที่แท็บนี้เสมอ) · ยังล็อก · เสร็จแล้ว พร้อมตัวเลขจำนวนบนแท็บ ไม่ต้องเลื่อนหาหัวข้อที่ทำได้อีก
  - การ์ดบอกหมวด, "ต้องวิจัยก่อน" และ "ปูทางไป" กดชื่อหัวข้อเพื่อไปที่หัวข้อนั้นได้ทันที
  - งานวิจัยที่กำลังทำปักไว้ด้านบนทุกแท็บ · แท็บเสร็จแล้วเป็นรายการแบบย่อ
- **โรงไฟฟ้าถ่านหินเผาเร็วขึ้น** จาก 1 ก้อน/5 วินาที (12 ก้อน/นาที) เป็น 1 ก้อน/2.5 วินาที (24 ก้อน/นาที) ใกล้เคียงกับที่เครื่องขุดถ่าน 1 เครื่องขุดได้ สายพานถ่านจึงไม่ค้างเพราะถ่านสำรองเต็มอีก
  - เครื่องขุดบนถ่านเกรดต่ำ (18 ก้อน/นาที) จะส่งไม่ทันเต็มที่ อัปเกรดเครื่องขุดหรือเพิ่มอีกเครื่อง
  - หน้าข้อมูลโรงไฟฟ้าแสดงแถบเชื้อเพลิงสำรอง อัตราการใช้ต่อนาที และคำแนะนำเมื่อสำรองเต็ม
- **สายพานอ้อมสายแร่มากขึ้น** ยอมเดินอ้อมได้ราว 12 ช่องแทนการลากผ่านช่องแร่ (เดิม 3 ช่อง) ช่องแร่จึงยังว่างไว้วางเครื่องขุดได้ · สายพานเดิมกด "จัดสายพาน" เพื่อให้เดินเส้นใหม่ได้
- หน้าต่าง "มีอะไรใหม่" แสดงเฉพาะเรื่องของเวอร์ชันที่ผู้เล่นยังไม่เคยเห็น: ผู้เล่นที่ข้าม v1.2.0 มาจะเห็นเรื่องโซนใหม่ด้วย ส่วนผู้เล่นที่เห็นแล้วจะเห็นแค่เรื่องหน้าวิจัย

### เซฟ
- ใช้เซฟเดิมได้ ไม่มีการเปลี่ยนรูปแบบเซฟ

## ไฟล์ในโฟลเดอร์นี้

- `index.html` — เปิดด้วยเบราว์เซอร์เพื่อเล่นเวอร์ชันนี้ได้ทันที (เซฟแยกจากเวอร์ชันอื่น)
- `update-from-v1.2.0.patch` — โค้ดที่เปลี่ยนจาก v1.2.0

## อัปเดตโค้ดจาก v1.2.0 เป็น v1.2.1

ถ้าโฟลเดอร์โปรเจกต์มีประวัติ git (มาจาก zip ชุดนี้):

```bash
git checkout v1.2.1
npm install
```

ถ้าโฟลเดอร์เป็นโค้ด v1.2.0 แบบไม่มี git:

```bash
git apply releases/v1.2.1/update-from-v1.2.0.patch
npm install
```
