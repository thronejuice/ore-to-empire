# Ore to Empire v0.7.1

**[0.7.1] - 2026-10-06**

### ปรับปรุง
- หน้าตั้งค่าแสดงเลขเวอร์ชันที่ถูกต้อง โดยอ่านจาก `package.json` อัตโนมัติ (เดิมเขียนตายตัวเป็น v0.4.0)
- เพิ่มระบบออกเวอร์ชัน: `CHANGELOG.md`, โฟลเดอร์ `releases/` และสคริปต์ `npm run release`

### เซฟ
- ใช้เซฟเดิมได้ ไม่มีการเปลี่ยนรูปแบบเซฟ

---

## ไฟล์ในโฟลเดอร์นี้

- `index.html` — เปิดด้วยเบราว์เซอร์เพื่อเล่นเวอร์ชันนี้ได้ทันที (เซฟแยกจากเวอร์ชันอื่น)
- `update-from-v0.7.0.patch` — โค้ดที่เปลี่ยนจาก v0.7.0

## อัปเดตโค้ดจาก v0.7.0 เป็น v0.7.1

ถ้าโฟลเดอร์โปรเจกต์มีประวัติ git (มาจาก zip ชุดนี้):

```bash
git checkout v0.7.1
npm install
```

ถ้าโฟลเดอร์เป็นโค้ด v0.7.0 แบบไม่มี git:

```bash
git apply releases/v0.7.1/update-from-v0.7.0.patch
npm install
```
